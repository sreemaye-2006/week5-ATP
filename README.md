# Week 5 - HTML Layouts & React Setup

This repository contains front-end development exercises, cleanly separated into raw HTML/CSS layouts and a React setup.

## Structure

### `html-assignments/`
This folder contains various static HTML/TailwindCSS layouts:
- **`simple-layout.html`**: A basic structure with top and bottom sections using Tailwind grids.
- **`pink-layout.html`**: A colorful layout demonstrating flexbox and basic cards.
- **`city-guide.html`**: A structured page acting as a Best City Guide with a hero section and content cards.
- **`flex-gallery.html`**: A responsive image gallery using CSS Grid/Flexbox.
- **`tables.html` & `tables.css`**: Demonstrates complex HTML tables with `rowspan` and `colspan`.

### `react-app/`
This folder contains a minimal Vite + React application setup.
- **`src/`**: Contains the main React components (`App.jsx`).
- **`public/`**: Static assets for the React application.
- **`vite.config.js`**: Configuration file for the Vite build tool.

## Note on React App
To run the React application, you would typically navigate to the `react-app` directory, run `npm install` to gather dependencies, and then run `npm run dev`.
